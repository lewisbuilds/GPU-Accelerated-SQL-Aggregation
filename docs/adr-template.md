# Architecture Decision Record (ADR) Template

**Title:** <concise decision title>

**Date:** <YYYY-MM-DD>

**Status:** Proposed | Accepted | Superseded by ADR-XXX | Deprecated

**Context**
Describe the forces at play: requirements, constraints, performance or security concerns, alternatives considered.

**Decision**
State the decision clearly in one paragraph.

**Rationale**
Why this option over others? Trade-offs (performance, complexity, risk) and rejected alternatives.

**Consequences**
Positive, negative, neutral outcomes. Operational impacts, migration needs, performance implications.

**Evidence / Benchmarks**
Insert key metrics (median log speedup deltas, CI bounds) or link to JSON artifacts / golden diff.

**Follow-ups**
List tasks (refactors, docs, tech debt cleanup) spawned by this decision.

**Accessibility & Security Notes**
Call out any user-impact or threat-model shifts.
